## Vedacta

Online compliance tools for companies selling into the European Union and for businesses in India, Japan, the UK and Brazil. Each tool answers one compliance question and names the law, article or official data file it rests on. Most run in the browser, so your files are not uploaded.

### European Union and Germany

| Site | What it does |
|---|---|
| [CBAM Exporter Pack](https://cbam.vedacta.com/) | EU CBAM cost calculator, official default values for 121 countries, emissions calculator, supplier letters and guides for steel, aluminium, cement and fertiliser exporters, in 20 languages. Paid Evidence Pack per plant and year |
| [EU Rules Finder](https://eurules.vedacta.com/) | Which EU product rules apply (GPSR, CRA, EUDR, batteries, packaging, ecodesign, ISO 9001/14001:2026), free generators and paid document kits as Word files, in 14 languages |
| [Heatbook](https://mtc.vedacta.com/) | Reads a mill test certificate (EN 10204 3.1) into a table of results, each value with its page and quote, in 6 languages |
| [E-Rechnung-Check](https://erechnung.vedacta.com/en) | Opens, checks and creates German e-invoices (XRechnung, ZUGFeRD) against the official KoSIT rules, in 8 languages |
| [Pay Gap Report](https://paygap.vedacta.com/) | Gender pay gap from a payroll file by the UK, Irish, Spanish or EU method, in 8 languages |
