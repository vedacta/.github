## Vedacta

Online tools for companies selling into the European Union, and for Indian businesses under the DPDP Act. Each tool answers one compliance question and names the regulation and article it rests on.

| Site | What it does |
|---|---|
| [CBAM Exporter Pack](https://cbam.vedacta.com/) | EU CBAM cost calculator by CN code to 2034, official default values for 121 countries, guides for steel, aluminium, cement and fertiliser exporters, in 19 languages |
| [EU Rules Finder](https://eurules.vedacta.com/) | Which EU product rules apply (GPSR, CRA, EUDR, batteries, packaging, ecodesign) and free generators for the documents they ask for, in 14 languages |
| [Heatbook](https://mtc.vedacta.com/) | Reads a mill test certificate (EN 10204 3.1) into a table of results, each value with its page and quote |
| [E-Rechnung-Check](https://erechnung.vedacta.com/en) | Opens and checks German e-invoices (XRechnung, ZUGFeRD) against the official KoSIT rules in the browser |
| [DPDP Notice Kit](https://dpdp.vedacta.com/) | Privacy notices under India's DPDP Act and Rules, in English and 10 Indian languages |

All tools: [vedacta.com](https://vedacta.com/) · Contact: contact@vedacta.com
